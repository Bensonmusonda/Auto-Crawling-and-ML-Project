# DeepSeek API Integration Roadmap

This document serves as the master record of the planned integration between the Auto Crawling & ML Project and the DeepSeek API. It is designed to preserve context across sessions.

## The Vision
To elevate the platform to a "Production-Grade SaaS" by leveraging Agentic AI (DeepSeek) to solve the hardest problems in data engineering: fragile web scrapers and messy, unstructured data.

## Strategic Brainstorm & Feasibility

### 1. Scraping: Automated Configurations & HTML Token Costs
* **The Problem:** Sending full HTML to an LLM for every page scraped is financially unviable due to token costs and context limits.
* **The Solution:** We already have a flexible `UniversalSpider` that takes a JSON config (CSS/XPath). DeepSeek will be used **once per site** to look at a stripped-down DOM and *generate* that JSON configuration. The Scrapy spider then uses that configuration to scrape the remaining 10,000 pages at zero token cost.

### 2. Scraping: Handling "Special Tasks" (Agentic Crawling)
* **The Problem:** The current `UniversalSpider` might only support basic modes like "Flat" or "List-Detail". What happens if a site requires clicking 3 dropdowns and solving a captcha before data appears?
* **The Solution:** We introduce an **Action DSL (Domain Specific Language)** mode. Instead of the LLM just returning selectors, it returns a sequence of actions: `[{"action": "click", "target": "#menu"}, {"action": "wait", "ms": 2000}]`. The `UniversalSpider` safely interprets this JSON array and drives Playwright. This allows DeepSeek to invent new navigation paths without executing dangerous, arbitrary Python code on our backend.

### 3. Processing: Agentic Pipeline Generation & Regex Generation
* **The Regex Solution:** Running an LLM operation on 50,000 rows of a Pandas DataFrame is too slow. Instead, send a 5-row sample to DeepSeek along with the user's intent. DeepSeek returns a Regex pattern. We apply that Regex pattern to the entire Pandas column instantly.
* **The Agentic Pipeline:** DeepSeek acts as an autonomous agent. We pass it the DataFrame shape, a 5-row random sample, and the schemas of all available operations in `strategies.py` (e.g., `impute`, `drop_missing`). DeepSeek analyzes the data and writes the optimal JSON pipeline configuration for the user.

### 4. Extension: AI-Assisted Selectors
* Instead of brittle absolute XPaths generated by browser APIs, the Chrome Extension will send a small chunk of localized HTML around the clicked element to DeepSeek. DeepSeek will identify semantic anchors (like `data-testid`) and return a robust CSS selector.

### 5. ML Training: AutoML Guide
* DeepSeek will analyze dataset statistics (column types, distribution) and act as an embedded Data Scientist, suggesting the optimal sklearn models and hyperparameter grids for the user's target variable.

## Execution Phases

### Phase 1: Agentic Processing & AI Regex (Currently Planned)
- Add `openai` to backend dependencies.
- Build the **Agentic Auto-Pipeline**: Feed DeepSeek the dataframe stats and available operations, returning a full `pipeline_config` JSON array.
- Build the **AI Regex Builder**: Generates Regex strings based on user prompts and sample rows, feeding into standard Pandas regex extraction operations.

### Phase 2: AI-Assisted Selectors (Extension)
- Update the Chrome extension to leverage DeepSeek for generating robust selectors based on localized HTML chunks.

### Phase 3: Zero-Shot Scraper Config & Action DSL
- Build a backend service that uses Playwright to load a URL, minifies the DOM, and asks DeepSeek to output the extraction schema.
- Implement the "Action DSL" to allow the LLM to define complex interaction flows without arbitrary code execution.

### Phase 4: ML Tuning Assistant
- Integrate DeepSeek into the ML Training dashboard to analyze datasets and suggest models/parameters.
